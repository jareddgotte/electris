# Security

Electris has no current supported release and no approved private vulnerability-reporting route.

## Reporting

- Do not file sensitive vulnerabilities as public issues.
- A future supported release requires an explicit, repository-approved private reporting route.
- Until that route exists, this remains a blocker rather than an invented contact method.

## Release security status

- Historical releases are unsupported archival artifacts.
- Claims about supported platforms require recorded target execution evidence.
- Signing, notarization, and credential ownership are blocked until separately approved and documented.
